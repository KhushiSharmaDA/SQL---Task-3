## Task 3 – SQL for Data Analysis

### Objective
To analyze a movie database using SQL and demonstrate core SQL concepts.

### Dataset
Movie database containing tables: movies, ratings, users, subscriptions, and genres.

### SQL Concepts Used
- SELECT, WHERE, GROUP BY, ORDER BY
- JOINS (INNER, LEFT)
- Subqueries
- Views
- Aggregate functions
- Indexing
